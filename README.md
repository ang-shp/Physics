# Дослідження характеристик лазерного випромінювання в напівпровідникових структурах 

Цей Jupyter Notebook (`Лабораторна_Лазер1.ipynb`) містить програмний код на Python для теоретичного та експериментального дослідження умов виникнення та ключових характеристик випромінювання напівпровідникових лазерів залежно від зміни температури.

---

## Мета проєкту

Дослідити спектральні характеристики напівпровідникового лазера, проаналізувати зміну інтенсивності випромінювання від довжини хвилі та енергії кванту при різних температурних режимах, а також оцінити температурні коефіцієнти і півширину спектру.

---

## Етапи аналізу та обробки даних

Програма послідовно виконує такі розрахунки та побудови графіків:

1. **Спектри інтенсивності від довжини хвилі:** Побудова експериментальних залежностей інтенсивності випромінювання лазера від довжини хвилі ($\lambda$) для всього діапазону температур.
2. **Спектри інтенсивності від енергії кванту:** Трансформація даних та побудова залежностей інтенсивності від енергії кванту ($E = h\nu$) для всіх значень температури.
3. **Аналіз півширини спектру:** Визначення півширини спектру випромінювання лазера (FWHM) та її порівняльне співвідношення з величиною теплової енергії $kT$.
4. **Температурний коефіцієнт:** Побудова залежності енергії кванту, що відповідає максимуму в спектрі, від температури ($T$) та лінійна апроксимація для оцінки температурного коефіцієнта зміни ширини забороненої зони / енергії піку.

---

## Вимоги до даних (Data Input)

Для коректної роботи коду та відтворення розрахунків у робочій директорії повинні знаходитися текстові файли даних. 
* **Формат файлів:** Текстові матриці/таблиці, що містять два стовпці: `Wave_Length` (довжина хвилі) та `Intensity` (інтенсивність випромінювання).
* **Умови:** Кожен файл має відповідати фіксованому значенню температури в діапазоні від 10 до 50 °C.

## Наукові висновки роботи

За результатами комп'ютерного моделювання та обробки експериментальних даних встановлено:
* Досліджено залежності інтенсивності випромінювання лазера в температурному діапазоні **від 10 до 50 °C**.
* Виявлено чітку закономірність: **зі збільшенням температури енергія кванту зменшується** (що пов'язано з температурним звуженням ширини забороненої зони напівпровідника).
* Розраховано, що значення півширини спектру випромінювання становить приблизно **0,05 $kT$**, що свідчить про високу монохроматичність лазерного випромінювання порівняно зі звичайними світлодіодами.
* Оцінено температурний коефіцієнт залежності енергії пікового кванту від температури, який становить **-0.45 меВ/К**.
